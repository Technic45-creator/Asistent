# Асистент 3.0 — тестова версія

Запуск з теки з `model_uk`, `comand.json`, `user.dat`: `python gui3.py` (GUI) або `python asistent3.py` (лише асистент).
GUI сам знаходить `asistent3.py/.exe` (потім `asistent`, `asistent2v`) і керує ним.
Самоперевірка логіки (без мікрофона і мережі): `python tests/selftest.py`; GUI без екрана: `python tests/selftest_gui.py`.

## Файли
| Файл | Що робить |
|---|---|
| `asistent3.py` | головний цикл, стани, зв'язок з GUI |
| `tts.py` | озвучення: SAPI або edge-tts, переривання, речення по черзі |
| `ai.py` | Gemini: потокова відповідь, виклик функцій, перевірка ключа, список моделей |
| `commands.py` | користувацькі та вбудовані команди (час, таймер, гучність, нотатки, пошук) |
| `stt.py` | необов'язковий Whisper для діалогу |
| `phrases.py` | різноманітні відповіді: `phrases.json` + вбудовані + варіанти від ШІ |
| `matching.py`, `uktext.py` | пошук команд; українські числа/тривалості, речення |
| `common.py` | шляхи, JSON (BOM, атомарний запис, `.bad`), логування з ротацією, API-ключ у keyring |
| `gui3.py` + `ui_forms.py` | GUI; згенерований Qt-код винесено в `ui_forms.py` |

## Нове
- **F9** — перервати мовлення і відповідь AI (`stop_hotkey`). Озвучення йде по реченнях.
- **AI виконує команди** (function calling): «зроби тихіше і постав таймер на п'ять хвилин». Невпізнана команда після активації йде до AI (`ai_fallback`).
- **Вбудовані команди:** «яка година / яка дата», «постав таймер на п'ять хвилин» / «скасуй таймер», «голосніше / тихіше / встанови гучність на сорок відсотків / вимкни звук», «запиши нотатку …» / «прочитай нотатки», «знайди в гуглі …». Ваші команди з `comand.json` мають пріоритет; вимкнути вбудовані: `"builtins": false`.
- **Індикатор стану** в GUI (очікує / слухаю / діалог / думаю / говорю / мікрофон вимкнено).
- **GUI:** кнопка «Перевірити ключ і обрати модель» (список моделей з API), поле «Що спрацює?» у вкладці команд, попередження про схожі ключові слова.
- **Журнал:** `asistent.log` з ротацією (512 КБ × 3).
- **API-ключ** зберігається в Диспетчері облікових даних Windows, якщо встановлено `keyring` (у `user.dat` тоді порожньо).
- `run_command` може мати `"args": ["prog", "arg"]` — запуск без shell. Нові дії у редакторі: `hotkey_map`, `start_dialog`, `exit`.

## Кольори журналу
Кожен рядок журналу розфарбовано за значенням (колір тексту + напівпрозора «плашка» фону):
| Колір | Що це |
|---|---|
| червоний (жирний) | помилки |
| жовтогарячий | попередження: «не знайдено», ігнорування, недоступний ШІ |
| зелений | виконана команда, «Асистент готовий» |
| білий/синій | що почув асистент (ваші слова) |
| бірюзовий | що каже асистент (`[TTS] >>>`) |
| фіолетовий | ШІ, фрази, Whisper |
| рожевий | активація (слово, F10, F9) |
| сіро-синій | службові повідомлення |

Категорію визначає тег рядка, а не слова в ньому: «Помилка виконання.», яку каже асистент, — це не помилка.
Вимкнути розфарбування: `"log_colors": false` у `seting.json`.
Вікно створення/редагування команди має ту саму тему (градієнт, «плашки» підписів, кнопки), що й головне.

## Різноманітні відповіді
Кожна фраза асистента («Слухаю вас», «Команду не знайдено», «Таймер запущено» тощо) має кілька варіантів,
і щоразу обирається випадковий, але не той самий, що минулого разу. Варіанти беруться з трьох джерел:
1. **`phrases.json`** — ваші варіанти. Кнопка **«Фрази: файл»** у налаштуваннях створює заготовку з усіма ключами
   і відкриває її. Для ключа, що є у файлі, ваші варіанти замінюють вбудовані. Зберегли файл — асистент підхопить
   зміни за секунду, перезапуск не потрібен. У фразах працюють `{name}` (ім'я асистента), `{user}` (ваше ім'я) і
   плейсхолдери ключа (`{duration}`, `{time}`, `{percent}`…); їх треба лишати без змін.
2. **Вбудовані варіанти** — працюють, навіть якщо файлу немає.
3. **ШІ.** Gemini заздалегідь придумує нові варіанти (стиль задає `phrases_style`) і зберігає їх у `phrases_ai.json`.
   Це відбувається у фоні через кілька секунд після старту, лише для нових чи змінених фраз і не частіше, ніж
   раз на `phrases_ai_refresh_days` (7) днів; озвучення лишається миттєвим. Кнопка **«Фрази: ШІ»** запускає
   генерацію одразу. Варіанти з неправильними плейсхолдерами, задовгі та дублікати відсіюються.
   Вимкнути: `"phrases_ai": false`. Увага: на сервер Google для цього йдуть тексти фраз і ваші відповіді команд (`speak`).

Відповіді ваших команд: у `comand.json` поле `"speak"` може бути списком — `"speak": ["Відкриваю.", "Уже відкриваю!"]`.
У вікні редагування команди варіанти розділяються символом `|`.

## Параметри `seting.json` (див. `seting.example.json`)
GUI керує іменем, гучністю, голосом SAPI, Mute; решта — вручну. Зміни підхоплюються без перезапуску
(крім `hotkey`/`stop_hotkey`).
- `tts_backend`: `"sapi"` (офлайн) або `"edge"` (потрібні `edge-tts` та інтернет; при збої — автоматично SAPI).
- `dialog_stt`: `"whisper"` — Vosk ріже звук на фрази, а розшифровує faster-whisper (перший запуск качає модель).
- `wake_grammar`: `true` — експеримент: у режимі очікування Vosk слухає лише слово активації (точніше, але
  «норі відкрий браузер» одним реченням тоді не спрацює — треба зробити паузу).
- `phrases_ai` (true), `phrases_style` («дружній, коротко»), `phrases_ai_variants` (6), `phrases_ai_refresh_days` (7).
- `ai_thinking_budget`: `0`, якщо модель повертає порожні відповіді через «мислення».

## Збірка (PyInstaller)
Додайте приховані імпорти для необов'язкових залежностей, якщо користуєтесь ними:
`--hidden-import keyring.backends.Windows --hidden-import edge_tts --hidden-import faster_whisper`.

## Відомі обмеження (не перевірялося на живому Windows)
Голос SAPI/edge, мікрофон, MCI-відтворення mp3, Whisper, граматика Vosk та Windows Credential Manager перевірені
лише на заглушках. `auto_update` у GUI досі нічого не робить (є підказка на галочці).
