# Asistent: голосовий асистент для Windows
 
Український голосовий асистент, який працює на вашому комп'ютері: слухає мікрофон **офлайн**, виконує ваші команди
(відкрити сайт чи програму, натиснути клавіші, поставити таймер, змінити гучність) і, коли ви цього захочете,
розмовляє з вами через **Google Gemini**. Має графічний інтерфейс із треєм, журналом і редактором команд.
 
> **Статус:** версія 2.6.1. Голос Windows, мікрофон,
> онлайн-голос Edge, Whisper і Credential Manager варто перевірити на вашій системі (див. [Відомі обмеження](#відомі-обмеження)).

## Можливості
 
**Голос**
- Активація словом (за замовчуванням «Норі» або «Асистент», ім'я змінюється в налаштуваннях) або клавішею **F10**.
- Команда одним реченням: «Норі, відкрий браузер». Якщо після активації команди немає, через 10 секунд асистент
  повертається в очікування.
- Офлайн-розпізнавання українською ([Vosk](https://alphacephei.com/vosk/)).
- Поки асистент говорить, мікрофон його не слухає (захист від відлуння). Є вимкнення мікрофона (Mute).
- **F9** перериває мовлення і відповідь ШІ.
**Команди**
- Власні команди в `comand.json`: відкрити сайт, запустити програму, виконати команду, натиснути гарячі клавіші,
  карта клавіш за словом, почати чи завершити діалог, вийти.
- Вбудовані команди: час і дата, таймер, гучність, нотатки, пошук у Google.
- Із кількох збігів спрацьовує команда з найдовшим ключовим словом, тому «вимкни звук» не вимикає комп'ютер.
**Діалог зі ШІ (Gemini)**
- Розмова з історією; відповідь озвучується по реченнях, поки приходить.
- ШІ сам виконує ваші команди та вбудовані дії (function calling): «зроби тихіше і постав таймер на п'ять хвилин».
- Нерозпізнана команда після активації йде до ШІ.
- Необов'язково: точніше розпізнавання в діалозі через Whisper.
**Озвучення**
- Офлайн-голос Windows (SAPI); голос, гучність і швидкість змінюються без перезапуску.
- Онлайн-голос Edge (`uk-UA-PolinaNeural`, `uk-UA-OstapNeural`); якщо він недоступний, автоматично вмикається SAPI.
**Різноманітні відповіді**
- Кожна фраза має кілька варіантів: ваші (`phrases.json`), вбудовані та придумані ШІ (кеш у `phrases_ai.json`).
**Графічний інтерфейс**
- Запуск і зупинка асистента, індикатор стану (очікує, слухаю, діалог, думаю, говорю, мікрофон вимкнено).
- Журнал, розфарбований за значенням рядків, з фільтрами.
- Редактор команд із перевіркою «Що спрацює?» та попередженням про схожі ключові слова; імпорт скриптів.
- Перевірка API-ключа і вибір моделі зі списку API.
- Автозапуск разом з Windows (згорнутим у трей), один екземпляр програми, HiDPI.

| | |
|---|---|
| ОС | Windows 10/11 (використовуються SAPI, реєстр, MCI, глобальні гарячі клавіші) |
| Python | 3.11–3.12, бажано 64-бітний (для `faster-whisper` 32-бітних збірок немає) |
| Мікрофон | підключений і обраний у Windows за замовчуванням, з дозволом для класичних програм |
| Модель Vosk | українська, у папці `model_uk` ([моделі Vosk](https://alphacephei.com/vosk/models)) |
| Український голос Windows | Параметри → Час і мова → Мовлення → Додати голоси |
| Ключ Gemini API | лише для діалогу, генерації фраз і списку моделей ([Google AI Studio](https://aistudio.google.com)) |
 
## Встановлення
 
```bat
git clone https://github.com/Technic45-creator/Asistent.git
cd Asistent
pip install -r requirements.txt
```
 
`requirements.txt` містить обов'язкові бібліотеки (`vosk`, `sounddevice`, `keyboard`, `requests`, `pywin32`, `PyQt5`) і
необов'язкові, які потрібні лише для відповідних функцій:
 
| Бібліотека | Навіщо |
|---|---|
| `keyring` | зберігати API-ключ у Диспетчері облікових даних Windows замість `user.dat` |
| `edge-tts` | онлайн-голос Edge (`"tts_backend": "edge"`) |
| `faster-whisper`, `numpy` | розпізнавання Whisper у діалозі (`"dialog_stt": "whisper"`) |
 
Розпакуйте українську модель Vosk у папку `model_uk` поруч із програмою.
 
## Швидкий старт
 
```bat
python gui3.py
```
 
1. При першому запуску відкриється вікно реєстрації: вкажіть ім'я, країну, місто та API-ключ Gemini (ключ потрібен
   лише для діалогу з ШІ; без нього працюють усі команди).
2. Натисніть **«Увімкнути»**. Коли в журналі з'явиться «Асистент готовий», скажіть «Норі, відкрий браузер»
   або натисніть F10 і скажіть команду.
3. Лише асистент без GUI: `python asistent3.py`.
Поруч із програмою мають лежати: `comand.json` (команди), `model_uk` (модель). Файли `user.dat`, `seting.json`,
`phrases.json`, `phrases_ai.json`, `notes.txt` і `asistent.log` програма створює й оновлює сама.
 
## Голосові команди
 
| Скажіть | Що станеться |
|---|---|
| «Норі, відкрий браузер» | спрацює команда з `comand.json` |
| «Яка зараз година» / «Яка сьогодні дата» | час або дата |
| «Постав таймер на п'ять хвилин» | таймер; по завершенні асистент скаже голосом («скасуй таймер» скасовує) |
| «Зроби голосніше» / «Тихіше» / «Вимкни звук» | системна гучність |
| «Встанови гучність на сорок відсотків» | конкретна гучність |
| «Запиши нотатку купити хліб» / «Прочитай нотатки» | нотатки у `notes.txt` |
| «Знайди в гуглі погода київ» | пошук у браузері |
| «Давай поговоримо» | діалог зі ШІ |
| «Стоп» / «Досить» (у діалозі) | вихід з діалогу, якщо така команда є в `comand.json`; також «стоп діалог» |
 
У діалозі команди не виконуються, але ШІ може викликати їх сам. Фраза «до зустрічі» (якщо є команда `exit`) завершує роботу.
 
## Налаштування
 
GUI керує іменем, гучністю, голосом SAPI, Mute, автозавантаженням, треєм і видимістю логів.
Решта параметрів лежить у `seting.json` (приклад: `seting.example.json`); зміни підхоплюються без перезапуску,
крім гарячих клавіш.
 
| Параметр | За замовчуванням | Що робить |
|---|---|---|
| `assistant_name` | `Норі` | ім'я та слово активації |
| `hotkey` / `stop_hotkey` | `f10` / `f9` | активація / перервати мовлення |
| `volume`, `tts_rate` | `45` (у GUI; `100`, якщо ключа немає), `2` | гучність мовлення 0–100, швидкість від -10 до 10 |
| `tts_backend` | `sapi` | `sapi` (офлайн) або `edge` (онлайн) |
| `edge_voice` | `uk-UA-PolinaNeural` | голос Edge |
| `active_timeout` | `10` | скільки секунд чекати команду після активації |
| `ai_stream` | `true` | озвучувати відповідь ШІ по реченнях |
| `ai_tools` | `true` | дозволити ШІ виконувати команди |
| `ai_fallback` | `true` | нерозпізнану команду віддавати ШІ |
| `builtins` | `true` | вбудовані команди (час, таймер, гучність, нотатки, пошук) |
| `dialog_stt` | `vosk` | `whisper` для точнішого розпізнавання в діалозі |
| `wake_grammar` | `false` | експеримент: слово активації через вузьку граматику Vosk |
| `phrases_ai` | `true` | ШІ дописує варіанти фраз у фоні |
| `log_colors` | `true` | розфарбований журнал |
| `ai_thinking_budget` | `null` | `0`, якщо модель повертає порожні відповіді через «мислення» |
 
## Ваші команди (`comand.json`)
 
```json
{
    "open_google": {
        "keywords": ["інтернет", "браузер"],
        "action": "open_website",
        "url": "https://www.google.com",
        "speak": ["Відкриваю браузер.", "Зараз відкрию, {user}."]
    },
    "shutdown": {
        "keywords": ["вимкни комп'ютер"],
        "action": "run_command",
        "cmd": "SlideToShutDown.exe",
        "speak": "Вимикаю комп'ютер.",
        "ai_variants": false
    }
}
```
 
| Поле | Значення |
|---|---|
| `keywords` | слова, за якими спрацьовує команда. Збіг іде з початку слова, а слова до 4 літер мають збігатися цілим словом |
| `action` | `open_website` (`url`), `launch_application` (`path`), `run_command` (`cmd` або `args` без shell), `hotkey` (`keys`), `hotkey_map` (`map`), `start_dialog`, `stop_dialog`, `exit` |
| `speak` | відповідь: рядок або список варіантів; доступні `{user}` і `{name}` |
| `disabled` | `true` вимикає команду |
| `ai_variants` | `false` забороняє ШІ придумувати варіанти відповіді |
 
Обережно з командами, що вимикають чи перезавантажують комп'ютер: добирайте для них довші ключові слова.
Перевірити, яка команда спрацює на фразу, можна в GUI: Налаштування → вкладка налаштувань команд → «Що спрацює?».
 
## Різноманітні відповіді
 
Кожна фраза асистента має кілька варіантів, і щоразу обирається випадковий, але не той самий, що минулого разу.
 
1. **`phrases.json`**: ваші варіанти. Кнопка «Фрази: файл» створює заготовку з усіма ключами. Ваші варіанти замінюють
   вбудовані для цього ключа, зміни підхоплюються за секунду. Доступні плейсхолдери `{name}`, `{user}` та специфічні
   для ключа (`{duration}`, `{time}`, `{percent}`…).
2. **Вбудовані варіанти**: працюють, навіть якщо файлу немає.
3. **ШІ**: Gemini заздалегідь придумує нові варіанти і кешує їх у `phrases_ai.json`. Це відбувається у фоні, лише для
   нових чи змінених фраз і не частіше, ніж раз на 7 днів, тож озвучення лишається миттєвим. Кнопка «Фрази: ШІ»
   запускає генерацію одразу.
## Структура проєкту
 
| Файл | Що робить |
|---|---|
| `gui3.py`, `ui_forms.py` | графічний інтерфейс (`ui_forms.py` — згенерований Qt-код) |
| `asistent3.py` | головний цикл асистента, стани, зв'язок з GUI |
| `commands.py` | користувацькі та вбудовані команди |
| `ai.py` | Gemini: діалог, потокова відповідь, function calling, перевірка ключа |
| `tts.py` | озвучення: SAPI або edge-tts, переривання |
| `stt.py` | необов'язковий Whisper |
| `phrases.py` | різноманітні відповіді |
| `matching.py`, `uktext.py` | пошук команд, українські числа й тривалості |
| `common.py` | шляхи, JSON-файли, логування, збереження API-ключа |
| `tests/` | самоперевірки логіки та GUI |
 
GUI запускає `asistent3` як окремий процес і спілкується з ним через stdin (`reload`, `stop`, `phrases`, `quit`).
Якщо GUI закрито чи він завис, асистент сам завершується і не лишає мікрофон увімкненим.
 
## Збірка exe
 
Потрібні `pip install pyinstaller pillow` і файли `ico.png`, `Setings.png` у папці збірки. Спочатку зробіть іконку:

GUI (без консольного вікна):
 
```bat
pyinstaller --noconfirm --clean --onefile --noconsole --name AsistentGUI --icon ico.ico --add-data "ico.png;." --add-data "Setings.png;." --collect-all keyring gui3.py
```
 
Асистент (назва має бути саме `asistent3`; консоль потрібна, GUI запускає його приховано і читає його вивід):
 
```bat
pyinstaller --noconfirm --clean --onefile --console --name asistent3 --icon ico.ico --collect-all vosk --collect-all sounddevice --collect-all keyring --hidden-import win32com.client --hidden-import pythoncom --hidden-import pywintypes asistent3.py
```
 
Покладіть обидва exe з `dist\` в одну папку з `model_uk` і `comand.json`. Для edge-голосу додайте до команди асистента
`--collect-all edge_tts --collect-all aiohttp`; для Whisper: `--collect-all faster_whisper --collect-all ctranslate2
--collect-all onnxruntime --collect-all av --collect-all tokenizers` (exe стане дуже великим).
 
Перший перевіряє логіку (команди, ШІ, озвучення, фрази, головний цикл) без мікрофона й мережі, другий — GUI без
екрана (потрібен PyQt5). Голос, мікрофон і мережа в тестах замінені заглушками.
 
## Конфіденційність і безпека
 
- **Розпізнавання мовлення працює офлайн.** До Google потрапляє лише текст, який ви говорите в діалозі зі ШІ або
  запускаєте через нерозпізнану команду, а також тексти фраз і поля `speak` ваших команд (для генерації варіантів).
  Вимкнути генерацію можна так: `"phrases_ai": false`.
- API-ключ зберігається в Диспетчері облікових даних Windows, якщо встановлено `keyring`; інакше лежить у `user.dat`.
  Не публікуйте `user.dat` у репозиторії.
- Команди `run_command` виконують те, що ви в них вказали. Для безпечнішого запуску використовуйте `args` замість `cmd`.
- У журнал `asistent.log` потрапляє те, що розпізнав асистент. Файл не передається нікуди.
## Відомі обмеження
 
- Версія 3.0 тестова: голос SAPI, онлайн-голос Edge (відтворення mp3 через MCI), Whisper, граматика слова
  активації та Credential Manager перевірені лише на заглушках.
- Перервати мовлення голосом неможливо (мікрофон мовчить, поки асистент говорить): використовуйте F9.
- З `wake_grammar` фраза «норі відкрий браузер» одним реченням не спрацює, треба зробити паузу.
- Параметр `auto_update` у GUI зарезервований і поки нічого не робить.
- Підтримується лише Windows.
## Вирішення проблем
 
| Проблема | Що робити |
|---|---|
|Немає голосу встанови голосову модель з rhvoice.org/uk-voices рекомендовано Marianna виберіть її в налаштуваннях |
| «Не вдалося відкрити мікрофон» | перевірте мікрофон за замовчуванням і Параметри → Конфіденційність → Мікрофон → дозволити класичним програмам |
| Мовлення звучить некоректно | встановіть український голос Windows (див. [Вимоги](#вимоги)) |
| Папка моделі не знайдена | розпакуйте модель Vosk у `model_uk` поруч із програмою, перевір наявність файлу model.conf(при встановлені нової моделі його не буде по замовчувані в новій моделіц)|
| F10/F9 не реагують у деяких вікнах | запустіть асистента від імені адміністратора: вікна з підвищеними правами не віддають гарячі клавіші |
| Діалог не працює | перевірте ключ кнопкою «Перевірити ключ і обрати модель» у налаштуваннях |
| Порожні відповіді ШІ | додайте `"ai_thinking_budget": 0` у `seting.json` |
| Щось інше | дивіться `asistent.log` поруч із програмою |
