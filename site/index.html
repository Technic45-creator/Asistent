Скажіть «Норі» — і комп’ютер слухає

Asistent ваш персональний помічник. Відкриває програми й сайти, вимикає комп’ютер, керує Spotify і відповідає на запитання за допомогою ШІ.

Як це працює

Три кроки від запуску до першої команди.

1.

Увімкніть

Натисніть «Увімкнути» у головному вікні. Статус зміниться на «працює».

2.

Покличте

Скажіть ім’я помічника — «Норі» — або натисніть клавішу F10.

3.

Скажіть команду

Наприклад, «відкрий браузер». Помічник виконає її й відповість голосом.

Що вміє Норі

Усе потрібне для щоденного керування комп’ютером голосом.

Голосове керування

Калькулятор, провідник, блокнот, робочий стіл, блокування, сон, перезавантаження та вимкнення — одним реченням.

Інтернет і музика

Відкриває Google і YouTube, запускає Spotify.

Відповіді від ШІ

Підключіть власний ключ API й оберіть модель — і Норі зможе підтримати розмову. Кнопка «Перевірити ключ і обрати модель» допоможе з налаштуванням.

Свої команди

Створюйте, редагуйте й видаляйте команди, імпортуйте власні скрипти. Фразу можна перевірити, не промовляючи її вголос.

Ваш голос і ваше ім’я

Оберіть голос серед встановлених у Windows, налаштуйте гучність і змініть ім’я помічника на будь-яке.

Працює тихо

Автозапуск із Windows, автооновлення, згортання в трей і вимикач мікрофона, коли потрібна тиша.

Інтерфейс

Простий інтерфейс із чотирма екранами. Натисніть на знімок, щоб збільшити.

Загальні налаштування

  • Голосова модель та гучність
  • Ім’я асистента
  • Автозавантаження й автооновлення
  • Відображення логів
  • Дані користувача, ключ API та модель ШІ

Додавання власних команд

Створіть команду за кілька хвилин: задайте фрази, за якими вона спрацьовує, і дію, яку виконає Норі.

1. Відкрийте форму

  1. У головному вікні натисніть кнопку із шестірнею.
  2. Перейдіть на вкладку «Налаштування команд».
  3. Натисніть «Створити». Відкриється вікно «Нова команда».

Хочете змінити наявну команду? Оберіть її у списку ліворуч і натисніть «Редагувати».

2. Заповніть поля

ID / Ключ командиУнікальна назва латиницею без пробілів, наприклад open_google.
Ключові слова (через кому)Слова й фрази, за якими команда спрацює: інтернет, браузер.
Тип дії (action)Що саме зробить команда. Оберіть зі списку.
Параметри дії (JSON)Налаштування дії у форматі JSON. Залежать від типу дії.
Відповідь (варіанти через |)Що скаже Норі. Кілька варіантів розділяйте рискою: Відкриваю браузер. | Зараз буде.

3. Оберіть тип дії

  • open_website — відкрити сайт
  • launch_application — запустити програму
  • run_command — виконати команду чи файл
  • hotkey, hotkey_map — натиснути комбінацію клавіш
  • start_dialog, stop_dialog — почати й завершити розмову
  • exit — закрити помічника

Не знаєте, як записати параметри для певного типу? Відкрийте схожу вбудовану команду кнопкою «Редагувати» і скопіюйте її параметри за зразок.

4. Приклад: команда «shutdown»

Так виглядає вбудована команда вимкнення комп’ютера.

ID / Ключshutdown
Ключові словавимкни, виключи, вимкнений
Тип діїrun_command
ВідповідьВимикаю комп’ютер.

Параметри дії (JSON):

{
    "cmd": "SlideToShutDown.exe"
}

Додатковий параметр "ai_variants": false (або true) вимикає і вмикає варіанти відповіді від ШІ для цієї команди. Додайте його в JSON через кому після інших параметрів:

{
    "cmd": "SlideToShutDown.exe",
    "ai_variants": false
}

5. Збережіть і перевірте

  1. Натисніть «Зберегти». Команда з’явиться у списку.
  2. У полі «Фраза для перевірки» введіть фразу, наприклад «вимкни комп’ютер».
  3. Натисніть «Що спрацює?». Помічник покаже, яка команда відповідає цій фразі, і нічого не виконає.

Є готовий скрипт? Скористайтеся кнопкою «Імпорт скрипта». Усі скрипти лежать у теці, яку відкриває кнопка «Відкрити теку скриптів».

Часті питання

Конфіденційність: куди потрапляють мої дані?

Нікуди. Усі налаштування, дані користувача, ключ API, логи та власні команди зберігаються лише на вашому комп’ютері й нікуди не відправляються. Розпізнавання команд і керування комп’ютером відбуваються локально. Якщо ви самостійно підключите ШІ зі своїм ключем API, текст запитів до ШІ надсилається сервісу цієї моделі — без цього підключення нічого не залишає ваш ПК.

Як змінити голос помічника?

Відкрийте налаштування (кнопка із шестірнею), на вкладці «Загальні налаштування» оберіть голосову модель зі списку. Доступні голоси, встановлені у вашій Windows. Додаткові українські голоси можна завантажити на сайті rhvoice.org/uk-voices — після встановлення вони з’являться у списку.

Чи можна змінити ім’я «Норі»?

Так. У налаштуваннях введіть будь-яке ім’я в полі «Ім’я асистента».

Чи потрібен ключ API?

Лише для відповідей від ШІ. Основні команди працюють без нього.

Як вимкнути мікрофон?

Увімкніть перемикач «Вимкнути мікрофон» у лівій частині головного вікна.

Як додати власну команду?

Перейдіть на вкладку «Налаштування команд» і натисніть «Створити» або «Імпорт скрипта». Покрокова інструкція з прикладом є в розділі «Додавання власних команд».
